## The task

A barbershop needed its own website that matched its brand and helped customers find services quickly.

## What I did

- Designed and built the whole site around the client’s business goals.
- Structured the code with object-oriented TypeScript so each component has one job and can be extended.
- Set up Webpack for modular builds and SCSS for maintainable styles.
- Built a responsive layout with interactive galleries and dynamic components.
